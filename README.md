# Skills

These are my [Agent Skills](https://agentskills.io), a standardized way to give AI agents new capabilities and expertise.

| Name | Summary |
| :- | :- |
| [`shadcn-theme`](/skills/shadcn-theme/) | Generate [shadcn/ui](https://shadcn.com/ui) themes as OKLCH CSS tokens. |
| [`draw-icons`](/skills/draw-icons/) | High-quality icons that match your product's vibe. |
| `create-content` | Content factory for carousels and Hyperframes videos. |

## Installation

You can add any of these skills using the [`skills`](https://skills.sh) CLI:

```bash
npx skills add ronykax/skills
```
